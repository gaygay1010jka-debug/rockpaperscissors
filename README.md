# rockpaperscissors

파이썬 배우고 가위바위보 게임 만들어봤습니다.

가위 바위 보 중 하나를 입력하면 됨니다.
숫자랑 영어로도 입력할수 있고 띄어쓰기나 느낌표 같은 것도 되게 만들었습니다.
오류 최대한 없게 만들엇습니다.

## 실행방법

```
python rockpaperscissors.py
```

파이썬 설치되있어야 됩니다.

## 지원하는 입력

- 가위 / 바위 / 보
- 1 / 2 / 3
- rock / paper / scissors
- 가위!, 가위ㅋㅋ 같은것도 됨
- 이모지도 됨
- 그 외 여러가지

사용자가 뭘 입력할지 몰라서 가능한 경우를 최대한 넣엇습니다.
그래서 코드가 좀 길긴 한데 대신 입력 거의다 됩니다.

처음 만든 게임이라 이상한 부분 있을수도 있습니다.
아직 모르는 문법이 많아서 일단 elif로 만들었습니다 ㅎㅎ
